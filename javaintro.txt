Introduction to JAVA:
Object-Oriented Programming (OOP) Fundamentals
OOP (Object-Oriented Programming) is a way of writing programs using objects and classes.
Example:
* Car → object
* Student → object
* Bank Account → object

🔹 Key Concepts of OOP
 1. Class

A class is a blueprint or template.
 Example:
`
Class: Student
Properties: name, age, marks
 2. Object

An object is a real instance of a class.
 Example:

Student s1 = new Student();
` 3. Encapsulation

Wrapping data and methods into a single unit.

 Protects data using private variables.

 Example:

private int age;

public void setAge(int a) {
    age = a;
}
 4. Inheritance

One class can reuse properties of another class.

 Example:

class Animal {
   void eat() {}
}

class Dog extends Animal {
   void bark() {}
}
 5. Polymorphism

Same method name → different behavior.
 Example:

void add(int a, int b) {}
void add(int a, int b, int c) {}
6. Abstraction

Hiding internal details and showing only important features.
 Example:
ATM machine → you don’t know internal working
 💻 Structure of a Java Program
🔹 Basic Structure

class ClassName {

    // Variables (Data members)
    
    // Methods (Functions)

    public static void main(String[] args) {
        // Execution starts here
    }
}
 🔹 Example Program
class Student {

    String name;
    int age;

    void display() {
        System.out.println(name + " " + age);
    }

    public static void main(String[] args) {
        Student s1 = new Student();
        s1.name = "Latha";
        s1.age = 20;
        s1.display();
    }
}
🔹 Explanation

* `class Student` → defines a class
* `String name, int age` → variables
* `display()` → method
* `main()` → starting point of program
* `new Student()` → creates object

AND(&):
Rule:
1 & 1 = 1
Otherwise = 0
int a = 5;   // 0101
int b = 3;   // 0011

int result = a & b;  // 0001 = 1
System.out.println(result);

OR (|):
5 = 0101
3 = 0011
-----------
    0111  = 1
Rule:
If any bit is 1 → result is 1
int result = 5 | 3;   // 0111 = 7

XOR (^):
5 = 0101
3 = 0011
-----------
    0110  = 6
Rule:
Same → 0
Different → 1
int result = 5 ^ 3;   // 0110 = 6

NOT(`)
  Flips all bits
  1 → 0
  0 → 1 
  ~n = -(n + 1)
  `5 = -(5+1)=-6
  `10 = -11
Left Shift (<<)
 Shifts bits to left (adds zeros on right)  
  int result = 5 << 1;   // 1010 = 10

Right Shift (>>)
Shifts bits to right
  int result = 8 >> 1;   // 0100 = 4

Unsigned Right Shift (>>>)
 Shifts right and fills with 0 (ignores sign)
